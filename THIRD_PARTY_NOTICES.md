# Third-party source used by this project

- `archive_format.py`: `resource_hash` and `make_archive` from [BingusSharedLoader/scripts/archive.py](https://github.com/CowboyBingus/BingusSharedLoader/blob/main/scripts/archive.py), CowboyBingus, 0BSD. The original project license permits use, copying, modification and distribution without conditions.
- `seat_release_040/src/bingus_text.lua`: byte-identical copy of the [ModOptionsMenu translation module](https://github.com/CowboyBingus/ModOptionsMenu/blob/main/src/bingus_text.lua), CowboyBingus, 0BSD. Menu locale text in `make_locales.py` was authored for this project.
- ModOptionsMenu and ModBindingsMenu are independent player-installed dependencies. Their source is downloaded locally for public-API tests; their packages, input configuration replacement and entire source checkouts are not included in this repository or this mod ZIP.
- Historical source folders retain references to other mod/tool projects and their original provenance in the corresponding research notes. Raw game archives, complete module captures and extracted game datasets are not distributed here.
