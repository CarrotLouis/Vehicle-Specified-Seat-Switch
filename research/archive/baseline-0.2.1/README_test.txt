当前状态
用户已验证 0.2.0 普通版单人和联机正常；本次保留其原生换座路径。
0.2.1 加强版修复尚未经游戏实测，仍是测试包，不能视为最终成品。
普通版：按原需求限制座位分组，调用游戏原生换座请求及空位检查。
加强版：在普通版基础上增加车内直接换座的单人测试路径。

支持的本机游戏版本
Steam build 25327279，EXE 1.8.45850.0。
只有模块指纹和接口特征均匹配时才启用。游戏更新后若不匹配，会停用并写日志。

安装
1. 关闭游戏。在 Arsenal 导入本 ZIP，打开模组选项，选择一个版本。
2. 保留并启用 Bingus Shared Loader v16，默认顺序下放在列表最下方。
3. 禁用此前的 Vehicle Seat Diagnostic 只读诊断包，按平时的方法部署。
4. 启动游戏。首次启动会自动建立两个版本共用的按键配置文件。
5. 切换普通/加强版本须退出游戏、在 Arsenal 改选、重新部署后再启动。

默认按键
普通版
M-102 Gunner FRV、M-103 Supply FRV：前排 F1 驾驶、F2 副驾驶；后排 F3 左、F4 右。

特殊任务油罐车：F1 驾驶、F2 炮位。

M-103：F1 驾驶、F2 副驾驶、F3 后左、F4 后右。

如果正在乘员位探身持个人武器，直接换座前会先尝试收起个人武器，再重新检查目标空位。

本次针对的反馈
1. M-102 机枪与 M-104 喷火位：补全炮位相机、持枪与身体状态准备。
2. 跨区域离座时先停止并解绑两条载具武器控制通道，恢复个人武器上下文。
3. Maelstrom 换出驾驶位时清理驾驶烟雾弹专属状态；再按新座位重新建立控制。
4. 校验角色动画资源后，将两个乘坐姿态层设为目标座位的最终状态，并处理本次排入的上车动画事件。
   目标是去掉跨区换座时的进入动画；实际姿态、视觉连续性及受击状态均需实测。
5. 确认 Maelstrom 资源标识，不再依赖候选推断；两型坦克保持独立按键配置。
6. 每次跨区换座记录各调用阶段。遇到状态或资源不匹配时拒绝操作或停用后续请求。

复测顺序
先在单人加强版验证 M-102、M-104：乘员→炮位的姿势，炮位→驾驶/乘员后旧炮是否仍跟随或开火。
再检查两型坦克：按住开火键跨区换座，旧武器是否停火；Maelstrom 换离驾驶位后能否继续使用烟雾弹。
最后连续往返跨区换座，确认始终留在车内、没有重复进入动画，并观察卡住或退出是否再现。
保留 Loader v16，先仅启用它和本模组做一轮对照；随后恢复其他模组，以区分模组组合影响。
这只是复测建议，本包不会自动改变其他模组的启用状态。
如果再次卡住或退出，请反馈车型、原位置/目标位置及大致时间；本机日志和转储可直接读取。
目前加强版联机跨区域尚未实现，联网时仍保留已验证的组内换座功能。

按键文件
%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/VehicleSeatSwitch.ini
可填 F1–F12、A–Z、0–9、NONE；同一车型内不可重复。修改后重启游戏生效。
[bastion] 与 [maelstrom] 可以分别设置。Arsenal 的版本选择不在此文件中修改。
同一按键长按只触发一次；目标是当前座位时不做操作。
窗口失焦、鼠标光标可见或原生载具输入未启用时不会处理换座键。
聊天等隐藏光标的界面仍需实测，建议保留默认 F 键。
