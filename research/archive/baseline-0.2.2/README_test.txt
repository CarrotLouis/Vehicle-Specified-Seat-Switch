安装
1. 关闭游戏。在 Arsenal 导入本 ZIP，打开模组选项，选择一个版本。
2. 保留并启用 Bingus Shared Loader v16，默认顺序下放在列表最下方。
3. 禁用此前的 Vehicle Seat Diagnostic 只读诊断包，按平时的方法部署。
4. 启动游戏。首次启动会自动建立两个版本共用的按键配置文件。
5. 切换普通/加强版本须退出游戏、在 Arsenal 改选、重新部署后再启动。

本次改动
1. 跨区域进入乘员位后，补上游戏正常换座使用的“重新装备当前个人武器”步骤。
   之前只恢复了武器显示/上下文，没有恢复射击控制通道，因而必须手动切枪。
   保留当前原生个人武器槽位；特殊状态沿用游戏自己的默认槽位回退规则。
   在调整座位前检查个人物品组件和角色身份，避免对缺失或不匹配的组件调用此接口。
2. 仍先停止并解绑旧座位的两条武器控制通道，不重新绑定旧机枪、喷火枪或坦克同轴机枪。
   保留 0.2.1 已验证有效的姿态、烟雾弹权限、炮位准备与进入动画修复。
3. 两版本共用的按键配置迁到 %APPDATA%/Arrowhead/Helldivers2/VehicleSeatSwitch.ini。
   新文件不存在时，优先迁移旧 Logs 目录内的配置；不删除旧文件、不覆盖已有新文件。
   默认仍为 F1–F5，新增 NUMPAD0–NUMPAD9 和 F13–F24 键名支持。
4. 本次只推进单人加强版。收到用户单人验收反馈后，再研究联机跨区域。

用户降低画质、帧数稳定后短期测试没有再遇到闪退；这不等于已经确定闪退根因。

复测顺序
在单人加强版中，先将常用主武器、副武器或支援武器选为当前武器，再进入载具。
测试 M-102、M-104 的炮位→乘员位，以及 FRV 前后排跨组→乘员位：直接探头并开火，不手动切枪。
测试 TD-220、TD-110 的驾驶位→左右乘员位：直接探头并开火，检查手上武器能否立即使用。
重复往返，并确认旧炮不会残留控制、持续开火，Maelstrom 驾驶烟雾弹不会跟到乘员位。
如果仍失败，请反馈车型、原座位/目标座位，以及当时选中的武器；日志可由本机直接读取。

按键文件
%APPDATA%\Arrowhead\Helldivers2\VehicleSeatSwitch.ini
首次用本版启动游戏后生成；按 Win+R 输入 %APPDATA%\Arrowhead\Helldivers2 即可找到。
可填 F1–F24、NUMPAD0–NUMPAD9、A–Z、0–9、NONE（禁用）；同一车型内不可重复。
用记事本修改并保存，重启游戏生效。用小键盘时需开启 Num Lock。
例如将 [m102] 的五项依次改为 NUMPAD1、NUMPAD2、NUMPAD3、NUMPAD4、NUMPAD5。
无小键盘可改 F6–F10；请按自己的游戏设置选择未占用键。
模组不会拦截游戏原有按键；沿用 F2/F3/F5 时，游戏性能面板仍可能响应。
[bastion] 与 [maelstrom] 可以分别设置。Arsenal 的版本选择不在此文件中修改。
同一按键长按只触发一次；目标是当前座位时不做操作。
窗口失焦、鼠标光标可见或原生载具输入未启用时不会处理换座键。
聊天等隐藏光标的界面仍需实测，建议保留默认 F 键。
