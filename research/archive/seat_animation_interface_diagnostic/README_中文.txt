Vehicle Specified Seat Switch — 0.7.2 动画同步接口只读定位

这不是修复包，也不提供跨区换座测试。
0.7.1已经确认：本机没有进入动画，朋友端仍播放进入动画。
本包只读取原生动画同步接口的消息登记、事件编号，以及玩家角色是否属于该接口处理对象。
不会调用这个动画接口，不会发出网络消息、安装拦截或修改游戏内存，不会自动换座。

本轮不需要朋友参与，只需单人采集：
1. 完全退出游戏。在Arsenal用本包替换0.7.1和所有其他旧诊断；只启用一个诊断包。
   保留 Bingus Shared Loader v16+ 和正式功能包0.2.4普通版。停用TankSeatKit等其他换座模组。
   所有诊断沿用同一个GUID和资源名，不能叠加。自定义INI保持不变。
2. 启动后，在自己的舰船等待约30秒。
3. 单人进入任务，正常上M-102机枪车的任意座位，停车坐稳约20秒。
   不必按Ctrl+Shift+Home，不需要换座、开火或切换控制权。
4. 正常退出游戏，回复“0.7.2动画接口定位完成”。此电脑的日志无需手动发送。

状态日志若出现complete，表示已取得5次连续的单人M-102座位接口样本，
不代表动画接口已证实可用于修复。没有看到complete也不要反复试，退出后让我检查日志。
程序有最多20分钟/1MB记录上限，未完成时会明确记录原因。

日志目录：%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs
详细日志：VehicleSeatAnimationInterface-日期时间-进程号-计时.log
状态日志：VehicleSeatAnimationInterfaceDiagnostic.log
同时保留VehicleSeatSwitch.log与BingusSharedLoader.log（若存在）。

与0.7.1的区别：
0.7.1的十秒动画采样已经完成，证明本机姿势保持正确。
0.7.2检查新发现的原生同步接口能否合法定位本人的角色与“动作结束”事件。
采集结果可能证明接口可用，也可能排除它；在确认前不会把它投入主动联机测试。
朋友始终无需安装模组，正式功能包不变。
