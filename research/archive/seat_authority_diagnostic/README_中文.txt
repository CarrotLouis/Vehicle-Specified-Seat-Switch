Vehicle Seat Authority Diagnostic 0.5.3 — 控制权往返实验

这是新的主动诊断，不是加强版联机功能包。只有你安装；朋友不用安装。
与0.4.3不同：Ctrl+Shift+Home 会主动提出一次车辆控制权移交请求；取得后立即尝试归还原控制者。不切换座位，不写占位/拥有标记，不自动下车或上车。
这条联网路径尚未经实际联机验证，实验可能被拒绝，也可能短暂影响朋友驾驶。日志中的 request_sent / return_sent 只表示发起调用，只有 probe_complete 表示已观察到归还。

安装
1. 完全退出游戏。在Arsenal禁用/替换0.5.2、0.5.1、0.5.0及所有旧换座诊断，只启用本包一个诊断。
2. 保留 Bingus Shared Loader v16 或更高版本，以及 Vehicle Specified Seat Switch 0.2.4 普通版。此轮不启用加强版。部署后启动游戏。
3. 在自己的舰船等约30秒，再加入朋友主持的双人任务。不要加入其他玩家。
本包沿用旧诊断的资源与管理器标识；不要同时启用旧诊断。不会修改自定义按键INI。不要叠加其他会改变载具座位或控制权的模组。

只做这一轮（朋友当房主，你当客机）
1. 使用 M-102 Gunner FRV。朋友先进入驾驶位，你进入前排副驾驶位。双方坐稳至少5秒，朋友把车停稳并松开行驶按键。
2. 保持游戏窗口在前台、关闭菜单/聊天。按住 Ctrl 和 Shift，轻按一次 Home，然后全部松开。不要同时按任何换座键。
3. 保持两人座位不变、车辆静止，等待30秒。不必重复按组合键。实验每次启动最多申请一次，并最多发起一次归还；超时也不会重复申请。
4. 30秒后，让朋友在原驾驶位尝试前进、左右转弯、刹停。观察是否还能正常驾驶、有无异常抖动、镜头或姿势变化。
5. 正常退出游戏，回复“0.5.3控制权往返诊断完成”，告诉我朋友能否正常驾驶、是否异常。无须再测你当房主，也不用按原来的a-f顺序。

触发没有画面提示或没有明显变化很正常：实验不改变座位。即使看起来没反应，也先完成上述等待并退出，日志会区分没有触发、条件不满足、请求未获准、成功归还。

日志
目录：%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs
状态：VehicleSeatAuthorityDiagnostic.log
详细：VehicleSeatAuthority-日期-时间-进程号-计时.log
同时保留 VehicleSeatSwitch.log 和 BingusSharedLoader.log。
若在这台电脑测试，完成后告诉我即可，我可直接读取。对外反馈时发送上述本次日志即可，无需整个游戏目录。

重要状态
transport_ready：被动收发记录已接入，还不代表可触发实验。
probe_armed：副驾、朋友驾驶、控制权和接口等条件已满足，可以按组合键。
probe_awaiting_acquire：已尝试申请，等待实际取得控制权。
probe_late_grant_watch：申请5秒未确认，仍观察迟到的移交，不重发。
probe_awaiting_return：已经取得，已尝试归还，等待实际归还。
probe_return_not_confirmed：归还5秒未确认，继续观察，不重发。
probe_complete：已取得并确认归还，至少两次观察跨越0.5秒均稳定。
probe_send_failed / probe_ended / disabled：未完成，不应当成成功。
详细日志中的 authority_probe_waiting 会说明具体不满足的条件；接口不识别时不会发出实验请求。

异常时
如果朋友无法驾驶、出现异常抖动或掉线，停止本轮，记录表现并退出任务/游戏，不要反复触发或继续跨区换座。需要临时恢复驾驶时，可由朋友正常下车后重新进入驾驶位；这是故障恢复操作，并非未来模组的换座方案。不要在归还尚未确认时把诊断停用当作“已经恢复”。
若 Ctrl+Shift+Home 已被你的换座INI用于任一座位，本包会拒绝主动实验。可先把那个自定义座位键改为其他键，完全重启后测试；诊断本身不更改INI。

实现边界
沿用0.4.3的辅助DLL和三个可写接口收发观察，原调用保持转交。新增通过现有 F8A9D630 包装器向当前控制者提出移交，再由本机原生接口请求归还。不开启多人加强版，不发送伪造的引擎通知，不修改可执行代码页。
申请前检查动态接口、注册表对应关系、具体会话实现、两个64位身份、角色/车辆身份和控制权状态；发送前重新读取。进入新房间、原对端离开或对象身份不符时不向旧目标发送。申请超时后仍观察迟到授予；没有确认归还会明确记录未完成。
离线验证和隔离Arsenal检查不等同于实际联机验证。此次需要的正是这一项新运行数据。
