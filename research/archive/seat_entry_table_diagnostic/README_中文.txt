Vehicle Seat Entry Table Diagnostic 0.1.0 / 载具入口表补充诊断

用途
补充此前0.4.2记录未包含的六种载具入口与座位对应表，共424字节。
这是另一类只读采集包，版本号0.1.0不表示退回旧版收发诊断。
不启用加强版多人跨区域换座。普通版/加强版功能包0.2.4均无需替换。

操作（仅需一次，不需要朋友）
1. 完全退出游戏。在Arsenal禁用旧诊断，用本ZIP替换；只启用一个诊断包。
   保留Bingus Shared Loader v16及当前换座功能包，重新部署。
2. 启动游戏，停留在自己的舰船约30秒。不用开始任务，不用召唤或驾驶载具。
3. 状态日志出现 entry_tables_complete 即完成；随后正常退出游戏。
   如果30秒仍未完成，可继续等到60秒；出现disabled则直接退出并反馈。
4. 回复“入口表补充诊断完成”。本机日志可以直接读取，不用手动上传。

日志位置
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs
VehicleSeatEntryTableDiagnostic.log（状态）
VehicleSeatEntryTables-日期时间-进程号-计时.log（独立数据）

范围
仅使用已核对的接口特征定位六段表格并读取，每段连读两次检查一致性。
424字节是表格有效采集量，不包含接口校验的代码读取和日志元数据。
不加载额外原生辅助DLL，不挂钩收发接口，不调用游戏原生换座函数，不写游戏内存。
不读取聊天、账号或IP，不更改INI，不发送实验消息。
已通过离线验证及隔离的Arsenal导入部署检查；尚待此次实际运行验证。
这些数据用于验证入口选择与空位回退逻辑，并不保证此方案最终能满足多人加强版要求。
