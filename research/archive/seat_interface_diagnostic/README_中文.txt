Vehicle Seat Interface Diagnostic 0.3.1 / 载具换座接口定位

本轮目的
接口诊断0.3.0已成功定位两个发送接口，十轮读取稳定，接口表页显示可写。
沿静态调用链进一步找到了接收分发入口、回调初始化和消息注册表。
本轮保留发送侧读取，新增接收回调地址/页属性/一致性检查，以及9类座位消息注册信息。
注册信息仅包括消息哈希、序号、标志字节、参数个数和类型索引，不是实际收发事件。
只读，不安装钩子、不调用游戏函数、不改座位、不替换函数指针、不改变内存保护。
不加载辅助DLL；不读取或改写按键INI；不采集玩家身份、聊天、IP或网络包。
可执行目标最多读取64字节代码用于和旧文件比对；不转储游戏堆。
页面标为可写不等于已经证明可以安全替换接口。此包不是加强版联机功能包。

使用方法
1. 完全退出游戏。在Arsenal移除或关闭旧Network/Protocol诊断包，导入本ZIP。
   同GUID会作为同一诊断工具的新版本；只保留一个诊断版本启用。
2. 启用 Bingus Shared Loader v16 + Vehicle Specified Seat Switch0.2.4普通版 + 本诊断。
   如仍有旧诊断部署文件，用Arsenal清理部署后重新部署。
3. 单人启动，在飞船留30秒，正常退出。无需进任务、按换座键或邀请朋友。
4. 回复“0.3.1接口定位已完成”。complete只表示10轮读取结束，并不保证指针有效。
   disabled/read_gap/routing_gap/不可用结果也有定位价值，请直接反馈，不必反复测试。

验证与限制
两份保留游戏采样的接口证据、五条独立引用和两个发送槽调用形式已离线核对。
新增6项接口证据和调用关系；接收初始化函数在旧采样中位置不同，仍通过特征重定位成功。
已覆盖空指针、不可读位置、读取期间指针变化、回调转交和采样上限。
注册表数量上限8192项，仅二分查找指定9种消息，不扫描全进程或记录其他消息内容。
最多10轮，每轮间隔至少2秒，日志上限256KiB，完成后自动停止。
初始化校验耗时较长时可能需要比30秒更多时间；日志会记录校验或读取失败。
Source内包含本次运行脚本和研究源码。构建脚本依赖本项目工作目录中的存档及工具。
尚未在真实游戏验证本包；普通版/单人加强版0.2.4及INI均未修改。
