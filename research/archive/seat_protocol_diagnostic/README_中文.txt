Vehicle Seat Protocol Diagnostic 0.2.1 / 载具换座协议诊断

本轮先做一次单人启动定位，不要重复双人测试。
上一份0.2.0在启动约5秒时出现 protocol_install_failed_310，协议事件为0。
310表示观察点安装时内存权限修改失败；这与两轮之间没有退出游戏无关。
本版补充原始Windows错误码、失败函数、目标内存页属性和回退结果；不重试或绕过权限限制。

本轮操作
1. 完全退出游戏，用本包替换0.2.0，保留Loader v16和换座普通版0.2.4，Arsenal重新部署。
2. 单人启动后留在飞船约30秒，无需邀请朋友或下任务。
3. 正常退出游戏，告诉本任务“启动定位已完成”，我会读取日志。
   即使仍显示disabled也无需再次尝试；这次错误明细本身就是所需数据。
4. 只有确认协议观察成功后，再安排下方的双人流程。

用途
研究只需使用者安装的联机跨区域换座。此包不会启用加强版联机功能。
在旧版座位/空位/控制权快照基础上，增加9类座位相关消息的原生发送调用、8个原生入口观察点
（其中一个是发送入口），以及调用顺序、时间、匿名对端标记、有限参数和本机按键事件。
修正旧诊断的本机角色识别问题，并保留光标接口共存修复。

安装（只需你的电脑）
1. 完全退出游戏。保留 Bingus Shared Loader v16、Vehicle Specified Seat Switch 0.2.4，选择普通版。
2. 用本 ZIP 替换旧 Vehicle Seat Network Diagnostic。只启用一个诊断版本，旧静态诊断也保持禁用。
3. Arsenal 中启用“协议诊断 / Protocol diagnostic”，Purge / Deploy。
4. 启动游戏后先留在飞船约30秒，不要立即下任务。
5. 查看 %LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\VehicleSeatProtocolDiagnostic.log。
   出现 protocol_ready 才表示协议观察已安装。只有 waiting_for_protocol/recording 不算准备完成。
   若出现 disabled、protocol_install_failed、helper_* 或接口校验错误，请停止，告诉本任务。
   无需重装普通版或修改 INI，也不要关闭系统/游戏保护来强行加载。
6. 先确认驾驶位与副驾驶位的自定义按键仍正常，再进行下面双人采集。

两轮短采集（暂不执行，启动问题解决后再使用）
使用 M-102 Gunner FRV，仅两人；队友不需要安装任何本项目模组。
第一轮你当房主；第二轮正常退出游戏、重新启动、等 protocol_ready 后，朋友当房主。
每个动作后停约3秒。顺序或次数略有差异没关系。
A. 你单独在前排：驾驶位和副驾驶位互换2次。
B. 朋友驾驶，你在副驾：尝试切入已占用的驾驶位；朋友下车后，再切到空驾驶位。
C. 朋友驾驶，你手动进入机枪位，转动/短暂点射并松开后离开；交换驾驶/机枪角色一次。
朋友观察你的位置、驾驶和武器控制是否正确。不要尝试自动跨区域换座；本次没有启用此功能。
双方下车后等5秒，正常退出游戏。完成后说明两轮谁当房主、大致时间、是否有异常。
若原换座功能失效、卡顿明显或行为异常，结束本轮并反馈，不要反复测试。

输出
同一 Logs 目录：
VehicleSeatProtocolDiagnostic.log：最新启动状态。
VehicleSeatProtocol-日期-时间-进程号-计时值.log：每次启动独立的数据，不覆盖上一轮。
VSSProtocol-指纹.dll：由包内嵌入数据自动生成的原生记录器缓存，无需手动放进游戏目录。
单份日志上限32MiB，达到上限停用记录。protocol_gap 会标记缓冲区争用/容量导致的漏记。
本电脑上的 Codex 可直接读取日志，无需上传完整游戏文件。

实现与边界
此版是被动观察器，但不再是“完全不写进程内存”的旧只读包：它用 MinHook 临时拦截8个
已校验的函数入口，把有限参数写入自己的缓冲区，再将原始调用原样转交一次。
不会主动调用换座函数、构造/发送新消息、改变原参数/返回值、修改座位或占位规则。
原生网络线程不会进入 Lua；Lua 定期取出缓冲数据写日志。停止时恢复入口，原生模块及跳板
保留到进程退出，避免仍在执行的调用引用已释放内存。禁用模组后需要重启游戏才能卸载。
校验依据接口代码与布局，地址可按特征重新定位；已核对25327279/25480438两份采集样本。
本包要求玩法包0.2.4，以保证其初始化字节校验先于诊断拦截完成。

native_send 表示调用了游戏的发送入口，不代表网络实际送达或收到确认。
native_handler 表示进入原生处理函数，也可能是本机分发，不能一律称为收到远端网络包。
P1/P2是与座位快照一致的会话标签；Q标签是暂未与会话表对应的对端；都不直接代表房主。
负值目标标签保留游戏原生广播选择，不推断“排除自己”的含义。
参数为短整数字段/浮点位模式/实体网络引用，不含聊天、账号资料或完整流量。
时间使用原生时间戳和序号，写入文件的顺序可能与采样快照交错。

验证范围
已做独立原生程序中的实际拦截、参数/返回值/浮点/LastError保留、多线程安装/停用、
缓冲溢出、无效指针和入口恢复测试；已做Lua初始化顺序、角色身份映射、两种加载顺序与
两版采集样本校验。已做Arsenal隔离环境的普通版/加强版共存部署检查。
尚未在实际游戏中验证这份新协议包；本次采集将提供这部分证据。

结束后
关闭游戏、禁用协议诊断并重新部署，保留玩法包及INI。
原生辅助模块由本项目源码编译，仅依赖Windows系统组件。

包内包含其许可证和相关源码。Loader：https://github.com/CowboyBingus/BingusSharedLoader
