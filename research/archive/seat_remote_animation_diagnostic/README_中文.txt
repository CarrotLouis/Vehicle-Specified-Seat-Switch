Vehicle Specified Seat Switch — 0.7.3 远端动画修正实验

本轮目标
上一轮已确认本人换座无上车动画，朋友仍看到上车动画。
本包在已验证的座位同步之后，向朋友发送一次游戏原有的动作结束通知。
需要确认朋友看到的是完全无动画、短暂动作，还是仍播放完整上车动画。
这是有实际换座和网络通知的限定测试包，不是只读采集包，也不是完整多人加强版。

安装
1. 完全退出游戏，在Arsenal移除/停用所有旧诊断，用本包替换；只启用一个诊断包。
   本包与旧诊断沿用同一标识和资源路径，不能叠加。
2. 保留Bingus Shared Loader v16+、Vehicle Specified Seat Switch 0.2.4普通版。
   本轮不要启用加强版、TankSeatKit或其他换座/控制权模组。INI不用修改。
3. 只有你安装，朋友不需要安装。在自己的舰船等约30秒，再加入朋友房间。
   VehicleSeatIntegratedDiagnostic.log出现transport_ready表示就绪。

只测一轮：朋友房主并始终驾驶M-102机枪车，你为客机，恰好两人
1. 朋友驾驶，你坐前排副驾驶。安全平地停车，坐稳至少5秒。
   双方松开移动、驾驶、瞄准、开火、交互键；你不探头，关闭菜单聊天。
2. 你按一次Ctrl+Shift+Home，到后排左座。松键后双方静止至少10秒。
   朋友重点观察你是否直接到达目标座位，是否有哪怕很短的起身/上车/滑入动作。
   本人也观察有无动作或错位。有条件可以录屏，但不要求额外安装录制工具。
3. 10秒后，你探头直接开火（不要先切枪），朋友再检查驾驶、转向、停车。
4. 第一次按键后至少间隔20秒，再停车坐稳、双方松键至少5秒。
   按一次Ctrl+Shift+Home返回副驾驶，同样先静止10秒，再检查开火和驾驶。
5. 正常下车，完全退出游戏。回复“0.7.3完成”，分别说明去程/回程：
   - 本人和朋友看到完全无动画、短暂动作，还是完整动画；
   - 座位位置、探头开火、朋友驾驶是否正常。

每次游戏启动最多两次操作，第三次按键不换座是预期限制。
不要连按，不要在本轮改用F1–F5测试跨区；这些键仍由普通版处理。
不测炮位/机枪位、驾驶位、其他车辆、本人房主或三/四人局。
若仅朋友仍有动画，可完成回程以便对比；若出现错位、失去驾驶、不能下车等新异常，停止操作并退出游戏保留日志。
状态出现disabled、incomplete、return_not_confirmed时不要再次尝试。

实现与边界
每次先核验当前实际通知处理接口、事件字典双向映射和本人角色身份。
事件编号现场读取，不硬编码0.7.2采集到的编号。不符合则拒绝新换座。
动作结束通知仅发给本轮唯一队友、只作用于本人的角色，每次最多一次，不重试/广播。
保留原控制权申请、实际取得、空位复查、同步、归还及失败清理流程。
沿用原来的原生记录助手，不增加钩子。新增通知由Lua调用前后日志记录；
原生助手仍只记录原来的15类消息，因此新增通知没有原生环形记录，也没有远端确认回执。
发送函数返回不代表朋友已收到，更不代表画面已修复，仍以这次双方观察为准。
离线测试通过；跨消息到达顺序、引擎处理时机和动画混合仍需要实际联机确认。
