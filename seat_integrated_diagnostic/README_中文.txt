Vehicle Specified Seat Switch — 0.7.0 控制权＋换座＋同步组合测试

主动测试包，尚不是完整的多人加强版。0.5.3验证控制权往返，0.6.0验证已拥有坦克时的换座同步；
本包第一次将两条路径合并，限定 M-102 机枪车副驾驶 ↔ 后排左座，朋友始终坐驾驶位。
只有使用者安装，朋友不需要模组。双方均留在车内，不执行上下车换座。
其他载具、机枪位、驾驶位切换、房主使用者以及三/四人局暂不在这轮范围。

安装
1. 完全退出游戏。在Arsenal替换0.5.3/0.6.0及其他旧诊断，只启用此包一个诊断。
   诊断沿用相同资源和管理器标识，不能叠加。继续禁用TankSeatKit及其他换座/控制权模组。
2. 保留Bingus Shared Loader v16+与功能包0.2.4普通版。本轮不要启用加强版。
   自定义按键INI不会被改写；普通版座位键保持原样。
3. 启动后在自己的舰船等待约30秒（接口扫描可能需要更久），再加入朋友主持的房间。
   状态日志出现transport_ready才表示记录接口已经接入。

只测一轮：朋友当房主，你当客机，房间恰好两人
1. 朋友正常进入M-102驾驶位，你正常进入前排副驾驶位。找安全平地停车，坐稳至少5秒，
   你松开开火/瞄准/移动/交互键，不探头，关闭菜单聊天。朋友停车松开驾驶键。
2. 按一次 Ctrl+Shift+Home，然后松开。不要同时按普通版换座键。
   模组会申请控制权，确认取得后重新检查空位，直接换到后排左座，发出同步，归还控制权。
   不是按键瞬间必定完成；等待至少3秒。状态日志integrated_operation_complete为详细日志事件，
   第一轮结束时状态日志会到integrated_waiting_second_trigger或随后准备返回的状态。
3. 让朋友观察你是否在后排左座、姿势是否正常。你探头并尝试直接使用手上武器，
   不先切枪；朋友确认射击表现。松开瞄准/射击。朋友试开、转向、停车，确认仍可驾驶。
4. 双方都正常才继续。第一次换座后至少等15秒，再次停车、不探头、坐稳至少5秒，
   再按一次 Ctrl+Shift+Home 返回副驾驶。等待至少3秒，重复检查你的位置、探头开火、
   朋友驾驶。之后正常下车，观察有无位置跳变；完全退出游戏。
5. 回复“0.7.0组合测试完成”，分别描述去后排、回副驾时双方看到的位置、姿势、
   探头是否能立即开火，以及朋友在每次换座后能否驾驶。

每次启动最多两次手动操作。不会自动开始第二次，也不会重发已调用的申请/归还。
这轮不要让朋友下车、换座或去占目标座位，不要加入第三人；这些竞争条件先在离线测试中处理。
如果第一步就有错位、朋友不能驾驶、无法开火等异常，不做第二步，记录现象并停止本轮。
若需要临时恢复朋友驾驶，可由朋友正常下车再上驾驶位；这是故障恢复，不是模组换座方案。

未触发/取消/恢复
- Ctrl+Shift+Home必须不附加Alt/Win，左右Ctrl/Shift均可。若INI已把此组合用于座位键，
  诊断会拒绝主动操作，避免双重触发；修改那一项后重启。F6不是测试键。
- 未取得控制权、目标占用/预留、探头、界面阻止输入、朋友不在驾驶位、身份或会话变化，
  均会拒绝或取消换座。日志显示具体原因。
- 申请超过5秒仍未确认时会取消换座，但继续观察迟到的控制权；若之后才取得，仍尝试归还。
- 换座失败或记录停止时，若已经取得控制权，会尽可能保持归还监测；不会盲目回滚座位。
  只有integrated_ownership_return_confirmed说明已实际观察到归还并稳定500毫秒。
- 出现return_not_confirmed/incomplete/disabled不代表已恢复。不要反复触发或把禁用诊断
  当作归还完成，记录情况并退出任务/游戏。会话已改变、原玩家离开或底层接口失效时无法保证自动归还。
