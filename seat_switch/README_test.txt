载具换座 0.2.3-test：键盘/鼠标组合键与单人驾驶换座修复

当前状态
用户已验证 0.2.0 普通版单人和联机正常；本次保留其原生换座路径。
用户反馈 0.2.1 单人加强版此前的姿势与武器控制残留问题基本修复；跨区进入乘员位仍需切枪才能射击。
用户测试 0.2.2 发现跨区到驾驶位再到副驾仍会武器失效，以及坦克按住转向换座后持续自旋。
本次 0.2.3 针对这两条反馈修复；新增键盘/鼠标组合键，尚待本次游戏内复测。
普通版：按原需求限制座位分组，调用游戏原生换座请求及空位检查。
加强版：在普通版基础上增加车内直接换座的单人测试路径。
加强版跨区域目前仅在单人且载具控制权属于本机时启用；完整联机跨区域尚未完成。
不会用自动下车再上车实现换座。多人时跨区域请求暂不执行。
两版均拒绝已占用或已被队友预留的座位；不能确认状态时不切换。

支持的本机游戏版本
Steam build 25327279，EXE 1.8.45850.0。
只有模块指纹和接口特征均匹配时才启用。游戏更新后若不匹配，会停用并写日志。

安装
1. 关闭游戏。在 Arsenal 导入本 ZIP，打开模组选项，选择一个版本。
2. 保留并启用 Bingus Shared Loader v16，默认顺序下放在列表最下方。
3. 禁用此前的 Vehicle Seat Diagnostic 只读诊断包，按平时的方法部署。
4. 启动游戏。首次启动会自动建立两个版本共用的按键配置文件。
5. 切换普通/加强版本须退出游戏、在 Arsenal 改选、重新部署后再启动。

本次改动
1. M-102/M-103/M-104 跨区到驾驶位时也重新建立当前个人武器绑定，供后续普通驾驶→副驾换座使用。
   保留此前跨区直接到乘员位的修复；坦克驾驶位沿用各自的原生武器配置。
2. 从驾驶位跨区离开之前，将载具保留的五项驾驶指令和两个按住按钮归零，清除持续转向来源。
   检查载具身份、组件和本机控制权，再比较写入并回读。不直接改变载具速度或位置。
   自然惯性、坡面滑动仍由游戏物理处理，不应再持续接受旧转向输入。
3. 新增标准键盘控制/标点/媒体键、鼠标五键（包括两个侧键）和修饰键组合。
   支持 CTRL+1、SHIFT+Q、CTRL+MOUSE4 等，默认仍 F1–F5。详见 KEYS_按键清单.txt。
   先按修饰键，再按主键；严格匹配修饰键，长按不重复，切回游戏不补触发。
4. 配置目录仍是 %APPDATA%/Arrowhead/Helldivers2/VehicleSeatSwitch.ini。
   保留已有配置；旧 Logs 目录迁移逻辑不变。
5. 保留前版已验证有效的姿态、旧炮停火/解绑、烟雾弹权限和进入动画修复。
   本次只推进单人加强版。收到用户单人验收反馈后，再研究联机跨区域。

闪退与 Loader v16
用户降低画质、帧数稳定后短期测试没有再遇到闪退；这不等于已经确定闪退根因。
本次不改图形设置，亦不声称修复显卡超时。继续沿用已核对的 Loader v16 / API 1 接口。

复测顺序
在单人加强版中，先将常用主武器、副武器或支援武器选为当前武器，再进入载具。
测试 M-102、M-104 的炮位→驾驶→副驾，以及 M-103 后排→驾驶→副驾：直接探头并开火，不手动切枪。
在 TD-220、TD-110 驾驶位分别按住 A 或 D，同时换到其他座位，再松开方向键，观察是否仍持续自旋。
再检查探头射击、下车后的坦克状态以及重新进入驾驶位后能否正常驾驶。
按键先试 CTRL+1、SHIFT+Q、CTRL+MOUSE4，检查单独主键、额外修饰键、长按、切回游戏的行为。
重复往返，并确认旧炮不会残留控制、持续开火，Maelstrom 驾驶烟雾弹不会跟到乘员位。
如果仍失败，请反馈车型、原座位/目标座位，以及当时选中的武器；日志可由本机直接读取。

按键文件
%APPDATA%\Arrowhead\Helldivers2\VehicleSeatSwitch.ini
首次用本版启动游戏后生成；按 Win+R 输入 %APPDATA%\Arrowhead\Helldivers2 即可找到。
合法名称及组合规则见随包 KEYS_按键清单.txt；同一车型内不可重复或重叠，NONE 表示禁用。
用记事本修改并保存，重启游戏生效。用小键盘时需开启 Num Lock。
例如将 [m102] 的五项依次改为 NUMPAD1、NUMPAD2、NUMPAD3、NUMPAD4、NUMPAD5。
无小键盘可改 F6–F10；请按自己的游戏设置选择未占用键。
模组不会拦截游戏原有按键；沿用 F2/F3/F5 时，游戏性能面板仍可能响应。
[bastion] 与 [maelstrom] 可以分别设置。Arsenal 的版本选择不在此文件中修改。
同一按键长按只触发一次；目标是当前座位时不做操作。
窗口失焦、鼠标光标可见或原生载具输入未启用时不会处理换座键。
聊天等隐藏光标的界面仍需实测，应避开会用于聊天或频繁操作的单独字母键。
Fn 等固件键、滚轮滚动及超过两枚的额外侧键不直接支持；额外侧键可先用厂商软件映射。
主回车和小键盘回车不能分别绑定。系统快捷键原本功能仍会执行。
